Drips

Guide home / Drips

Goal: create running paint when the nozzle lingers close to a surface.

Set up the scene

  1. Add one PaintDripSystem and one PaintDripRenderer. These are persistent singletons; avoid adding another pair for every tool.
  2. On PaintDripRenderer, check Drip Shader and Profile Tex. The package provides PaintDrip.shader.
  3. On every receiving mesh, put a non-convex MeshCollider on the same GameObject as its renderer.
  4. Include that renderer in PaintReceiver's Renderers list and enable Allow Drips.
  5. Add PaintDripEmitter to the nozzle, with its forward axis aimed at the surface.
  6. Connect the controller to call DetectDrip(...) each frame while painting.

The receiver must have valid settings, paint UVs, and materials. If no valid renderer/non-convex MeshCollider pair is found when it enables, the receiver turns Allow Drips off. Fix the collider setup, enable Allow Drips again, and re-enable the receiver.

Use stationary surfaces for the initial setup. Moving or deforming receivers need separate testing.

Make a drip appear

Move close to the surface, aim roughly perpendicular to it, and hold the nozzle nearly still while painting.

Emitter controlDefaultEffect
Ray Distance0.07 mMaximum distance for drip detection; independent of the projector's Far Clip
Max Speed0.1Maximum calculated surface-hit movement speed for accumulation
Accumulation Speed4Higher values build up paint faster
Drip Threshold1Accumulation must exceed this value to emit a drip
LayersDefault layer onlyCollider layers checked by the emitter

Opacity, distance, and surface angle also affect buildup. The emitter ignores trigger colliders. After emitting, it locks until the hit position moves enough; holding it perfectly still does not create an endless series of new drips.

Tune the visible trail

Adjust Drip Size on PaintDripRenderer for trail width. Thin trails can disappear at low receiver resolution; check surface resolution before increasing simulation work.

If nothing appears, check the shader and profile, mesh Read/Write where needed, both scene components, emitter range and layers, and whether the receiver is ready to paint. A PaintReceiverProxy alone does not make a collider support drips.
