Spray Projector guide

Spray Projector adds paint to meshes in a Universal Render Pipeline (URP) or High Definition Render Pipeline (HDRP) scene. A projector is the nozzle or brush; a receiver is the surface that holds the paint. Settings assets let you reuse a paint style or surface setup.

The package is com.stencg.sprayprojector. Install the package you received through Unity Package Manager from disk, or place it at Packages/com.stencg.sprayprojector as an embedded package. Choose one installation method per project; remove a previous installation before switching locations to avoid duplicate script and asset GUIDs.

Start here

  1. Install Spray package and try sample to explore the assembled tools.
  2. Set up your own scene using a working projector and receiver.
  3. Prepare paintable surfaces, including materials and UVs.
  4. Tune the paint for spray, marker, or stamp styles.
  5. Save and reload your work before building a larger scene.
