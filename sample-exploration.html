Install and import sample

  1. Install Spray Projector in a Unity 6 project using URP or HDRP.
  2. In Package Manager, import Spray Demo Common, then import Spray Demo URP or Spray Demo HDRP for the project's active pipeline.
  3. Open SampleScene.unity from Assets/Samples/Spray Projector/<installed version>/Spray Demo URP/, or SampleSceneHDRP.unity from Spray Demo HDRP/.

Common contains the scripts, prefabs, settings, UI, and textures used by either scene. The pipeline sample contains its own receiver materials and scene. Importing a scene without Common leaves its shared references unresolved.

An older imported Spray Demo can remain in the project while you try the new samples. The new layout uses distinct asset GUIDs and assembly names. Keep only the scenes you need in the build and avoid opening both demos together, since each scene creates its own input and paint controllers.

Imported samples are editable copies. Changes to them do not update the package.

Set up input on SampleScene

Legacy Input Manager onlyEnable StandaloneInputModule component and disable InputSystemUIInputModule

Check Active Input Handling in Player Settings and keep one UI input module active. The sample selects its painting input backend automatically.

With Both selected, the sample uses its Input System adapter, so keep InputSystemUIInputModule enabled. If Input System is not installed for a legacy-only project, remove its missing component from the imported EventSystem. The backend does not change project settings automatically.

The imported sample is an editable copy, not a live link to the package sample. Preserve local changes before reimporting. Avoid importing multiple versions of the new Common sample at once because they use the same assembly names.

Explore the tools

Enter Play Mode and use the Game view.

Clear deletes saved work. Use a disposable test drawing while exploring. Read Saving and loading before using these controls on artwork you want to keep.

Inspect a working setup

Select a tool and follow its PaintProjector Settings reference to the style asset. Then select a receiving surface and inspect its material, PaintReceiver, Receiver Settings, UVs, and collider.

The sample controllers use Unity Events to connect input to painting. If a button does nothing, check its On Click or controller event bindings for missing targets or methods as well as checking the input module.

Copy or duplicate the working prefabs and settings into your own folders under Assets before adapting them.
