Near Clip and Far Clip limit where paint reaches the surface. The apex offsets are ignored for orthogonal projection.

Tune opacity and surface finish

Pressure is passed into the projector as the paint color's alpha. Pressure Curve changes its response; Pressure Multiplier on the projector supplies an additional multiplier.

During paint rendering, both Angle Factor Curve and Far Clip Curve use pressure after Pressure Curve and Pressure Multiplier, with interpolation between stroke samples. The Angle Factor Curve tooltip describes raw pressure, but the current drawing code uses the processed value. Receiver-detection raycasts evaluate Far Clip Curve with raw input alpha, so unusual curves can produce a difference between detection range and the rendered mark. When comparing styles, keep input pressure and distance consistent.

  • Use Dark Paint Compensation if dark paint looks too transparent.
  • Use Bright Paint Compensation if bright paint needs more coverage.
  • Adjust Metalness, Smoothness, and Wetness on the projector for the finish.
  • Enable the receiver's additional texture and drying features as needed to display those effects.

Input alpha below 0.01 stops painting. This threshold is checked before the pressure curve.

Preview, erase, and clear

A controller calls PreviewProjection(color) while aiming. Preview Strength controls its visibility. When projectors compete for a receiver's preview, higher Preview Importance takes priority.

Erase Mode makes Paint remove paint within the projected mark. Stop() ends the stroke and clears preview state controlled by that projector.

ClearTarget() releases the hit receiver's current paint and preview textures using a forward ray up to 2 metres. It does not delete saved files; saved paint can return on the next load. For permanent clearing, see Saving and loading.
