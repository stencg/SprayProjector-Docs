Set up your own scene

Guide home / Getting started

Goal: paint onto one surface, then reuse that setup. For a first installation, start with the Spray Demo, which already connects painting, input, and UI.

1. Create your settings assets

  1. In the Project window, choose a folder under Assets for your own settings.
  2. Use Assets > Create > Spray Projector > Paint Settings.
  3. Use Assets > Create > Spray Projector > Receiver Settings.
  4. Select each asset and check its references using the table below.

The Editor fills missing package shader, compute, and noise references when these assets are imported. It does not choose a paint profile for you. Duplicating an imported demo settings asset is also a useful starting point.

Create your project's settings under Assets, or duplicate the imported demo settings. SampleReceiverSettings.asset belongs to the optional sample; assign settings explicitly to your own receivers.

AssetCheck in the Inspector
Paint SettingsPaint Shader uses PaintProjector.shader; assign a Profile Texture for the mark.
Receiver SettingsPaint Shader also uses PaintProjector.shader; Extend Uv Island Shader uses DilatingUv.shader; TextureToBuffer16.compute and TextureToBuffer32.compute assigned to their matching fields.

The Receiver Settings Paint Shader is a processing shader, not the Lit or Unlit shader used by the visible surface material. Both compute references are required by receiver initialization.

2. Prepare one surface

  1. Use a mesh with non-overlapping islands inside the 0-1 tile.
  2. Assign a material using one of the supplied Paint Receiver shaders: PaintReceiverLit and PaintReceiverUnlit. A normal URP Lit material alone does not display accumulated paint.
  3. Add PaintReceiver component on surface GameObject and assign Receiver Settings asset.
  4. Check its Renderers list. An empty list automatically collects renderers on the object and its active children.
  5. Add a collider. For the simplest setup, keep the collider, renderer, and receiver on the same GameObject.
  6. In the PaintReceiver component menu, choose Calculate UV World Scale.
  7. Turn off Allow Drips if you do not need them.
  8. For saving, choose Generate New ID once and keep that ID stable on your scene.

3. Prepare group of surfaces

  1. Prepare meshes so they share single UV tile space and similar scale. It allows you to use single PaintReceiver for a group for shared paint texture.
  2. In PaintReceiver, check its Renderers list and set directly required to paint renderers to prevent automatic collecting.
  3. Set colliders to each Renderer.

See Paintable surfaces for collider variants, UV preparation, and seam settings.

The PaintReceiver context menu includes Calculate UV World Scale and Generate New ID. For batch setup across open scenes, use Window > UI Toolkit > Paint Tools.

If Receiver Settings was missing when the component initialized: assign it, then re-enable the component. It disables itself after logging an error.

4. Add a painting projector

  1. Add PaintProjector to a nozzle GameObject and assign your Paint Settings.
  2. Point its local forward axis (+Z) toward the surface.
  3. Set its Layers mask to include the surface's collider layer. The default mask includes only the Default layer.
  4. Place the surface between the Near Clip and Far Clip distances in Paint Settings.
  5. Connect a controller like in supplied Sample that calls Paint(...) while painting and Stop() when painting ends.

Adding a projector alone does not make it spray. Reuse the demo's connected tool prefab, or ask a developer to connect your input using the Scripting API. Aiming preview uses PreviewProjection(...).

5. Test the result

Enter Play Mode, aim at the surface, and paint a slow stroke. Move the tool to check that the mark stays attached to the mesh. Test edges and UV seams, then tune the paint style.

Initialization and loading can take time; the first paint call may only prepare the receiver. Continue calling Paint while the input is held.
