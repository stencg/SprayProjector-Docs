Paintable surfaces

Guide home / Paintable surfaces

Goal: prepare a mesh that holds paint in the correct place, at a useful resolution.

Choose a receiver material

Use one of the supplied Paint Receiver materials or create a material from the package's Lit or Unlit Shader Graph: PaintReceiverLit and PaintReceiverUnlit. In HDRP, choose Opaque or Transparent Surface Type on each material. The Lit graph also supports material-level Alpha Clipping; turn it off for solid or transparent surfaces, and turn it on for cutout surfaces. The optimized Lit shader supports URP only. These shaders are in the package's Packages/Spray Projector/Runtime/Shaders folder.

The visible material must support the package's paint properties, including _PaintTexture and, for additional paint data, _PaintMetallic. Assigning a standard URP or HDRP material does not add this support.

Prepare the paint UVs

Painting automatically uses UV1 or, if exists, the second UV channel, called mesh.uv2 in Unity's scripting API. The supplied paint-writing shaders read this channel directly.

  • Keep paint UV islands within the 0–1 tile.
  • Consider to add a second UV channel if the first one is outside tile.
  • Avoid overlapping islands unless you deliberately want the same paint to appear in multiple places.
  • Leave at least 4 px padding between islands to reduce bleeding at seams.
  • Keep a reasonably consistent UV scale so strokes have similar sharpness across the surface.
  • If several renderers share one receiver, they also share its paint textures. Arrange their paint UVs accordingly, or use separate receivers.

The Calculate UV World Scale tool measures UV1 when present and falls back to UV0 for its calculation. That fallback does not change which UV channel the shaders paint into.

Set paint resolution

  1. Open the PaintReceiver component menu and choose Calculate UV World Scale.
  2. Check UV World Scale and Paint Textures Aspect Ratio on the receiver.
  3. Set Pixels Per Unit and Maximum Texture Dimension in Receiver Settings.
  4. Paint thin and broad strokes at the expected viewing distance.

The scale calculator reads a MeshFilter on the receiver's own GameObject and requires a readable mesh. It does not search child meshes or average the Renderers list. For a receiver on an empty parent, set UV World Scale from the child meshes' intended scale and check the result on the group.

More pixels make fine marks easier to see but cost texture memory. The maximum dimension caps the result, so increasing Pixels Per Unit may eventually stop improving sharpness.

Finalize resolution and UV layout before saving production paint. Changing them later can make old data incompatible or move marks onto different parts of the mesh.

Connect the collider

Surface setupWhat to use
Simple paintable objectCollider and PaintReceiver on the same GameObject
Child mesh under a receiverMeshCollider on the listed renderer's GameObject; the receiver registers this pair
Separate collision object for ordinary paintingPaintReceiverProxy on the collider object, with Receiver assigned
Surface that receives dripsNon-convex MeshCollider on each receiving renderer's GameObject, plus Allow Drips

A parent receiver is not discovered by an unrestricted search up the hierarchy. Use the registered renderer/MeshCollider pair or an explicit proxy where needed.

For drips, enable mesh Read/Write where needed for valid mesh hit data. Start with stationary geometry and see Drips. A proxy alone does not register a drip surface.
