Doubling both texture dimensions roughly quadruples their pixel memory. Raise resolution only where it makes a visible difference at the expected viewing distance.

Reduce work per stroke

  • Keep paintable meshes reasonably simple; painting draws their geometry again.
  • Limit material slots on receivers when possible.
  • On lower-end hardware such as Quest 3, painting more than 1,000 vertices of rendered receiver geometry in total for a stroke can significantly affect rendering performance; simplify paintable meshes and profile on the target.
  • Balance interpolation spacing in PaintSettings - Interpolation Step Size against visible gaps in fast strokes.
  • Use only the raycast layers the projector needs.
  • Add drips where the effect matters; their simulation performs extra raycasts and rendering.
  • Tune Shadow Resolution by comparing occlusion quality and cost.

Manage larger scenes

ReceiversManager uses camera distance and a VRAM target to move receivers between full textures, saved previews, and released textures. Assign Main Camera, or provide a camera tagged MainCamera.

This workflow relies on saving and valid receiver IDs to preserve artwork while releasing textures. Important Preview retains selected previews during relevant cleanup paths; it is not a promise that full-resolution paint textures stay allocated.

The manager's memory figure is an estimate, not the device's total GPU memory usage.

Saving and Loading speed

ReceiverSettings provide two important parameters to control texture bytes stream:

  • Read Data Chunk - higher value provides higher speed of loading.
  • Write Data Chunk - higher value provides higher speed of saving.

For example, you want to double speed so increase those values x2.

Remember The 85k Rule: chunk size requiring 85k bytes or more goes straight to the Large Object Heap memory (LOH). PaintRecievers use pooled array of bytes for chunks to prevent massive LOH bloating.

Other recommendations

  • Warm up the shader variants used by your project before measuring first-use performance.
  • Define DEBUG_SPRAY for more detailed logs when diagnosing package behavior.

Check the actual target

Use the Unity Profiler, Frame Debugger, GPU timing, and Memory Profiler in a target Player. Check both first use and repeated painting, saving, moving between distance bands, and simultaneous tools.

For VR, also test the actual controller bindings and headset rendering. Editor results and successful builds do not establish mobile or Quest performance.
