Troubleshooting

Guide home / Troubleshooting

Start with a single receiver and tool. Check the Console before changing visual settings.

Nothing is painted

  1. Confirm PaintProjector and PaintReceiver are enabled.
  2. Check their Settings references and the receiver's two compute shader references.
  3. Confirm the controller calls Paint repeatedly while input is held; adding the projector alone does not spray.
  4. Check that input alpha is at least 0.01 and Pressure Multiplier is not zero.
  5. Aim +Z toward the collider, within the configured clip range.
  6. Include the collider's layer in the projector's Layers mask.
  7. Use a Paint Receiver material and valid second-channel paint UVs.
  8. Allow warmup/loading to finish.

For a child or separate collider, use a registered renderer/MeshCollider pair or PaintReceiverProxy. Arbitrary parent lookup is not automatic.

The receiver disables itself

Missing Receiver Settings produces an error and disables the component. Assign the settings asset, check its processing resources, and re-enable PaintReceiver.

The projector disables itself during initialization

Check its Paint Settings and Paint Shader. In the binary package, Player builds also check the license during initialization. If the Console reports Projector initialization failed., ask the package maintainer to check the license setup. Source package builds and Editor Play Mode do not send license requests.

Marks repeat, smear, or land in the wrong place

Check UV1 / mesh.uv2, the channel used by the paint-writing shaders. Overlapping islands repeat paint; a missing or unsuitable second UV channel cannot be fixed by changing Pixels Per Unit.

If several renderers share a receiver, check their combined UV layout. The UV-scale calculator's UV0 fallback is only a measurement fallback.

Thin strokes or drips disappear

Increase receiver resolution within a practical texture budget, or use a wider profile or Drip Size. Check whether Maximum Texture Dimension is already capping the result.

For visible seams, try Fix Seams, check the extension shader, and remove negative local scale. Seam fixing affects paint color, not the additional-data texture.

Drips do not appear

  • Add both PaintDripSystem and PaintDripRenderer.
  • Check the drip shader and profile.
  • Call DetectDrip each frame while painting.
  • Use a non-convex MeshCollider on the receiving renderer's GameObject.
  • Check mesh Read/Write where needed and enable Allow Drips again if initialization turned it off.
  • Move within the emitter's Ray Distance; its default is only 0.07 m.
  • Check emitter Layers, opacity, nozzle angle, and slow movement.

After one emission, move the nozzle slightly to release the emitter's lock. See Drips.

Preview behaves unexpectedly

Distinguish the aiming preview from a saved-paint preview. PreviewProjection controls the former; the demo Preview button controls the latter.

For competing aiming previews, check Preview Importance. Stop clears preview state controlled by that projector. For a blurry saved preview, return to painting to prepare full textures.

Paint comes back after clearing

ClearTarget releases textures but keeps saved files. The next load can restore them. Use the appropriate permanent clear operation only if you intend to delete the saved artwork; see Saving and loading.

Saving or reloading fails

Check unique, stable receiver IDs, Allow Saving, both compute shaders, GPU readback support, and writable persistent storage. Wait for any current save or load to finish.

Keep UV layout, UV World Scale, texture aspect ratio, Pixels Per Unit, and Maximum Texture Dimension consistent with the saved artwork. The demo Reload action handles dirty receivers only.

The sample UI or mouse tools do not respond

Install uGUI and match the EventSystem module to Active Input Handling. Keep only one UI input module enabled. For legacy-only input, remove a missing Input System component if present.

Check a MainCamera-tagged camera for mouse raycasts, and inspect the controller's Unity Events and button On Click bindings for missing methods. See Sample exploration.
